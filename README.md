# AlgoLassi FileRecovery Releases

Official Windows x64 releases of AlgoLassi FileRecovery.

## Downloads

Download published versions from the Releases page.

## Verify downloads

Use PowerShell to calculate the SHA-256 checksum:

```powershell
Get-FileHash .\AlgoLassi.FileRecovery.exe -Algorithm SHA256
```

Compare the result with the checksum in the corresponding release notes.

File recovery is not guaranteed. Save recovered files to a different drive.

This repository contains release information and binaries only. Source code is not published here.
